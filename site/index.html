A few questions

Which assistants can use it?

Any MCP-compatible client, from desktop assistants to IDE agents. Add it to the client's MCP server config with uvx, or run it over stdio or streamable HTTP.

Is a signal proof that a drug causes an event?

No. FAERS holds voluntary reports, and a signal is a statistical association that deserves review. The server tells the assistant to present results that way, never as medical advice.

Do I need an API key?

No. An openFDA key is optional and free; it raises the limit from 1,000 to 120,000 requests a day.

What happens when nothing matches?

openFDA answers 404 when nothing matches, and the server returns an empty list instead of an error. Bad inputs return a clear message to the model.
